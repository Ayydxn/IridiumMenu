# Iridium

A powerful, free and open source mod menu for Geometry Dash based on the [Eclipse Menu](https://eclipse.menu/).

It aims to be more actively updated and maintained as well as add hacks that are present in other mod menus like Mega Hack, but are absent in Eclipse.

## Reporting Issues

If you encounter any issues while using Iridium, please don't hesitate to open an issue on the **GitHub Repository**.
